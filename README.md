# Caesar Cryptograph 🔐

Консольна програма на Java для шифрування та дешифрування тексту за допомогою алгоритму Цезаря. Проєкт створений як
навчальна робота для освоєння основ Java Syntax та роботи з файловою системою.

## 🌟 Особливості

* **Багатомовність**: Автоматичне визначення алфавіту (Українська та Англійська... ).
* **Гнучкість**: Підтримка роботи через аргументи командного рядка та інтерактивний режим (Scanner).
* **Brute Force**: Можливість автоматичного перебору всіх можливих ключів для дешифрування.
* **Надійність**: Власна система обробки помилок (FileProcessingException).
* **Чиста назва**: Автоматичне додавання суфіксів `[ENCRYPTED]` та `[DECRYPTED]` без їх дублювання.

## 🛠️ Як запустити

### Вимоги

* Java JRE / JDK 11 або новішої версії.

### Запуск

- #### Через параметри

В параметрах запуску програми потрібно вказати наступне:

- Для шифрування:
  ENCRYPT "file path" key

- Для дешифрування:
  DECRYPT "file path" key

- Для використання Brute Force:
  BRUTE_FORCE "file path"

- #### Інтерактивний режим

Якщо запустити без параметрів, програма запропонує ввести дані крок за кроком

### 📂 Структура проєкту

Проєкт реалізований згідно з принципом розподілу відповідальності (Separation of Concerns):

- CryptographRunner — точка входу.

-- domain

- Command - enum-класс для збереження команд
- Alphabet - клас для збережння мов

-- exception

- FileProcessingException — кастомний клас помилок.

-- filemanager

- FileManager — робота з файловою системою.

-- functional

- CaesarCipher — математична логіка шифрування.
- CLIServise - отримання аргументів від користувача(інтерактивний режим)
- CommandProcessor — визначення режиму запуску(через параметри \ інтерактивний режим) та виклик необхідної команди.
- LanguageChecker - логіка обробки конкретної мови(ENG\UA)

### 📝 Приклад роботи

Ви вказуєте параметри ENCRYPT secret.txt 3

Програма автоматично розпізнає мову тексту.

Після шифрування з ключем 3 створюється новий файл secret[ENCRYPTED].txt.

Оригінальний файл залишається без змін.
